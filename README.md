# Full-Stack App — Node.js + Python on AWS EC2

## Structure
```
project/
├── nodejs-app/     # Express REST API (port 3000)
├── python-app/     # Flask REST API  (port 5000)
└── .gitlab-ci.yml  # CI/CD Pipeline
```

## Quick Start
```bash
# Node.js
cd nodejs-app && npm install && npm start

# Python
cd python-app && pip install -r requirements.txt && python app.py
```
